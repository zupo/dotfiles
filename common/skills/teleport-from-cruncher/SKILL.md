description: From zbook, select and pull a Claude Code or Codex conversation and working changes from cruncher, then resume that agent locally in Rex. Use to bring remote work back to the Mac.

Run on zbook. Source is a selected conversation on cruncher (`/home/zupo`); destination is zbook (`/Users/zupo`). Use pull mode in [the teleport workflow](../teleport.md). The local conversation invoking this skill is the coordinator, not the conversation to transfer. If invoked elsewhere, explain that this skill must run on zbook and stop.
